# Multi-Factor Authentication (MFA)

Applies to: all corporate accounts. Method: Microsoft Authenticator.

## Setting up MFA for the first time
1. Install Microsoft Authenticator from the App Store or Google Play.
2. On a computer, go to `https://mysignins.acme-corp.com/security-info`.
3. Click "Add sign-in method", choose "Authenticator app", and scan the QR code with the app.
4. Approve the test notification to finish.

## Not receiving MFA prompts
- Open the Authenticator app manually; pending requests often appear only when the app is open.
- Make sure notifications are allowed for the app in your phone settings.
- Check that the phone's date and time are set automatically. Wrong time breaks one-time codes.
- As a fallback, choose "Use a verification code" on the sign-in screen and type the 6-digit code from the app.

## Got a new phone
Before wiping the old phone, add the new phone at the security-info page above. If the old phone is already gone, the Service Desk must issue a Temporary Access Pass after verifying your identity.

## Unexpected MFA prompts
If you receive an MFA prompt you did not start, deny it and change your password immediately. Do not approve prompts you did not trigger.
